# Mobile

This folder will contain the **DevFácil** mobile application, built with React Native (Expo).

## Planned Structure

```
mobile/
├── src/
│   ├── components/       # Reusable UI components
│   ├── screens/          # App screens (Login, Home, Requests...)
│   ├── navigation/       # React Navigation configuration
│   ├── services/         # API calls (axios/fetch)
│   └── context/          # Global state (AuthContext, etc.)
├── app.json              # Expo configuration
├── package.json
└── tsconfig.json
```

## Getting Started

```bash
# Install dependencies
npm install

# Start Expo dev server
npx expo start
```
